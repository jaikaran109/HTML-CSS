# HTML CSS Practice Repository

This repository contains my HTML and CSS practice files, lessons, and mini projects.

## What This Repo Covers

- Basic HTML structure
- Headings, paragraphs, and text formatting
- Links, images, and lists
- Forms and input fields
- Buttons, labels, textarea, and select
- CSS selectors and styling basics
- Colors, backgrounds, borders, and border-radius
- Margin, padding, and box model
- Width, height, spacing, and alignment
- `box-sizing`, `display`, and positioning
- Flexbox layout basics
- Simple page layouts and UI practice
- Mini project building with HTML and CSS

## Practice Projects Included

- Tribute website
- Job application form
- Shapes-based UI practice
- Multiple lesson and exercise files

## How to Run

Open any `.html` file in your browser, or use Live Server in VS Code.
